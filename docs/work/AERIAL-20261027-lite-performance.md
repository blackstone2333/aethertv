# AERIAL-20261027-lite-performance

Status: review
Owner: main model

## Spec

- 目标：压缩桌面运行内存，改善当贝 F3 的 Lite 航拍负担，并保留玻璃方向光、焦点伸展、圆角及独立材质/明暗偏好。
- 用户反馈：F3 Full 在桌面航拍时卡顿；电视管家显示桌面约 178 MB（进程总 PSS）。目标电视目前关机，先在 Redmi K40S 验证。
- 验收：Lite 不在播放期间另开取帧解码器；视频和可重建图片缓存有明确容量边界；手机 Release 同条件记录优化前后 PSS，保留统计口径；双 Release、受影响单测及 APK 契约通过。
- 不承诺未经实测的 F3 内存降幅或 Full 等效动态折射；F3 硬解码、流畅度及内存标记未验证。原版数值需注明同机、素材、模式和统计条件。
- 范围：航拍播放/暂停生命周期、玻璃缓存及 Lite 材质、图片与网格派生绘制缓存、性能回归测试和文档。单 Owner，不委派；不顺带合入新上游功能。
- 安全：Java 17、com.dangbei.tvlauncher、namespace app.orchard.tv、Android 5/6 兼容；不动原厂桌面、默认 HOME、无障碍或用户数据。优化版本 0.3.1，安装序号独立递增。

## Status

- 原因：Lite沿用了旧SurfaceView取帧回退，播放时每2.5秒额外开MediaMetadataRetriever；Android6没有PixelCopy。1080p读前缓冲24MiB也与Full相同。网格为屏外应用保留两份派生face，全局烘焙只限32项、缩略图无字节上限。
- 已实现：Lite不打开取帧器；视频缓冲1080p/4K/Dolby为8/12/16MiB，保留原画质选择。复制失败时保留暂停平面，进面板后回已有壁纸并释放解码器；进程内保存播放位置，恢复不依赖能否复制帧。
- 已实现：视口附近保留face缓存，完整应用/焦点节点不变；全局bakes限8MiB、缩略图4MiB，不回收UI持有图片。静态Lite玻璃最长边768px，菜单共用材质/明暗；运动Dock只绘透明填充与方向光，焦点弹簧只缩放缓存端态。
- 已实现：Lite不保留控制中心全屏Home截图，面板停留时释放航拍播放器；处理失败/取消的PixelCopy临时图与取帧缩放临时图。
- 构建、L0及L1实施验收通过；本包review等待F3实机与用户观感验收。

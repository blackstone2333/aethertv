## 执行规则

- 每天北京时间 10:00 在当前开发会话检查；由 Codex 的线程自动化执行，名称“AetherTV 上游精选同步”。无变化时安静。
- 先读仓库规则和当前工作包。工作树有未提交改动、正在实施相同文件或构建时，只登记待审提交，不覆盖开发中的文件。
- `git fetch upstream` 后逐项看行为和依赖；在 `codex/aerial/` 分支实施，使用 Java 17，按受影响范围测试和构建两个 Release。
- 冲突保留 AetherTV 的包名、配置、更新渠道、自由排布、播放偏好、系统工具、IPTV 和设备安全边界。适用的新增/修复/优化逐项吸收，不能因为版本号更新整包替换。
- 保留用户保存的排序、文件、照片、源和偏好。不能自动改默认桌面、守护权限、签名或发布正式 Release。
- 每次提交记录上游 SHA、实际选入内容、暂缓理由及验证级别。只有完整集成后才能把该提交标为已合入；部分提取必须写清范围。
